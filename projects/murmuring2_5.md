## 📝 개요
기존 비동기 음성 공유 서비스에
**실시간 오디오 라이브 방송 기능을 추가한 프로젝트**입니다.

**Android 단독 개발자**로 참여하여 RemoteMonster SDK를 활용한
실시간 오디오 방송 기능과 채팅 시스템을 구현했으며,
라이브 생성·참여·종료 등 방송 전반의 Android 기능을 개발했습니다.

## 🚀 주요 기여

### 1. 실시간 오디오 라이브 기능 개발

- WebRTC 기반 **RemoteMonster SDK를 Android 앱에 연동**
- 실시간 음성 송수신을 활용한 **오디오 라이브 방송 기능 구현**
- 방송 생성·참여·퇴장 등 **라이브 방송 라이프사이클 처리**
- 방송 상태 변화에 따른 **Android UI 및 상태 처리 로직 구현**

### 2. 실시간 채팅 기능 개발

- 라이브 방송 중 스트리머와 참여자가 소통할 수 있는 **실시간 채팅 기능 구현**
- 채팅 메시지 송수신 및 **메시지 목록 UI 개발**
- 방송 상태와 채팅 화면을 연동하여 **라이브 방송 내 커뮤니케이션 기능 구현**

### 3. 라이브 방송 사용자 흐름 구현

- 방송 생성부터 참여·시청·종료까지 이어지는 **라이브 방송 사용자 흐름 구현**
- 라이브 방송 기능의 **화면 및 상태 전환 로직 개발**
- 라이브 UX 시나리오 및 **기능 정의 과정 참여**
