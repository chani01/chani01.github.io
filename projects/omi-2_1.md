## 📝 개요
신체 재활 중심의 기존 서비스에 **우울·불안 심리검사와 챌린지 기능을 추가**하며
건강관리 서비스의 기능 영역을 확장했습니다.

강원 2024 동계청소년올림픽에서는 컬링 대표팀을 위한
**건강관리 챌린지 기능을 개발하고 실제 운영을 지원**했습니다.

## 🚀 주요 기여

### 1. 심리검사 기능 개발

- 수술 후 사용자의 정서 상태 확인을 위한 **우울·불안 심리검사 기능 개발**
- 검사 문항 진행부터 결과 확인까지 **Android UI 및 데이터 처리 로직 구현**
- 검사 결과를 사용자가 쉽게 확인할 수 있도록 **결과 데이터 시각화**
- 수술·시술 유형에 따른 **재활 운동 콘텐츠 기능 확장**

### 2. 챌린지 시스템 개발

- 강원 2024 동계청소년올림픽 **컬링 대표팀 건강관리 챌린지 기능 개발**
- 챌린지 목표·진행 상태·달성 여부를 확인할 수 있는 **Android 기능 및 UI 구현**
- 일반 사용자를 대상으로 한 **목표 달성형 운동 챌린지 기능 개발**

### 3. Jetpack Compose 기반 UI 구조 개선

- 심리검사 문항과 챌린지 유형 변화에 대응할 수 있도록 **재사용 가능한 Compose 컴포넌트 구성**
- 상태에 따라 화면이 변경될 수 있도록 **동적 UI 구현**
- 공통 UI 요소를 컴포넌트화하여 **기능 추가 및 화면 변경에 대응하기 쉬운 구조로 개선**
