## 🚀 주요 기여

### 1. AI 꿈 분석 엔진 연동
- AI 모델 연동으로 사용자 꿈 텍스트를 **심리적 의미로 해석하는 핵심 로직** 구현
- 분석 작업을 **백그라운드 처리**하여 UX 흐름 유지

### 2. 데이터 관리 구조 설계
- **Cloud Firestore** 실시간 동기화 + **Room** 로컬 캐싱으로 오프라인 환경 대응
- 날짜·키워드별 꿈 히스토리 **아카이브 기능** 구현

### 3. Jetpack Compose 기반 UI 구축
- Compose 전면 도입으로 **현대적인 선언형 UI** 구현
