## 📝 개요
사용자가 기록한 꿈을 AI를 활용해 분석하고,
분석 결과와 과거의 꿈 기록을 확인할 수 있는 서비스입니다.

**Android 단독 개발자**로 참여하여 앱 아키텍처 설계부터
AI 분석 기능 연동, 데이터 저장 구조, Jetpack Compose 기반 UI까지
Android 앱 전반을 개발했습니다.

## 🚀 주요 기여

### 1. AI 기반 꿈 분석 기능 연동

- 사용자가 입력한 꿈 텍스트를 AI에 전달하고 **분석 결과를 제공하는 기능 구현**
- AI 분석 요청 및 응답 데이터를 Android 앱에서 처리하는 **연동 로직 개발**
- 분석 작업 중에도 사용자가 앱을 계속 이용할 수 있도록 **백그라운드 처리 구현**
- 분석 결과를 앱 화면에서 확인할 수 있도록 **UI 및 상태 처리 로직 개발**

### 2. Cloud Firestore 기반 백엔드 및 데이터 구조 설계

- 서비스 요구사항을 기반으로 **Cloud Firestore 데이터 모델 및 Collection 구조 직접 설계**
- 사용자·꿈 기록·AI 분석 결과 등 서비스 데이터를 관리하기 위한 **Firestore 저장 구조 구현**
- Android 앱과 Firestore 간 **데이터 저장·조회·동기화 로직 설계 및 구현**
- Room을 활용한 **로컬 데이터 저장 및 캐싱 구조 구성**
- Firestore와 Room을 연계한 **클라우드·로컬 데이터 관리 구조 구현**
- 날짜·키워드를 기준으로 이전 꿈 기록을 확인할 수 있는 **히스토리 기능 개발**

### 3. Jetpack Compose 기반 UI 개발

- Jetpack Compose를 활용하여 **앱 주요 화면 및 UI 컴포넌트 구현**
- 화면 상태에 따라 UI가 변경될 수 있도록 **상태 기반 화면 구성**
- 반복적으로 사용되는 UI 요소를 **재사용 가능한 Compose 컴포넌트로 구성**
