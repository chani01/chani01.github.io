## 📝 개요
음성을 기반으로 사용자 간 소통과 이야기를 이어갈 수 있도록 개발한
**오디오 소셜 네트워크 프로젝트**입니다.

**Android 단독 개발자**로 참여하여 ExoPlayer 기반 오디오 재생,
백그라운드 연속 재생, 음성 릴레이 기능 및 UI 등
Android 앱 전반을 설계하고 구현했습니다.

기존 Java 기반 프로젝트에 Kotlin을 도입하고
MVP 아키텍처를 적용하여 신규 기능 개발과 코드 구조 개선을 진행했습니다.

## 🚀 주요 기여

### 1. ExoPlayer 기반 오디오 재생 기능 개발

- ExoPlayer를 활용한 **음성 스트리밍 및 플레이리스트 재생 기능 구현**
- 앱이 백그라운드 상태에서도 재생을 이어갈 수 있도록 **백그라운드 오디오 재생 기능 개발**
- 다수의 음성 콘텐츠를 연속으로 재생할 수 있는 **플레이리스트 제어 로직 구현**
- 음성 데이터 재생을 위한 **캐싱 및 플레이어 상태 관리 로직 개발**

### 2. 음성 릴레이 SNS 기능 개발

- 사용자가 기존 음성 콘텐츠에 음성으로 응답하며 이야기를 이어갈 수 있는 **릴레이 기능 설계 및 구현**
- 음성 콘텐츠 간 연결 관계를 확인하고 새로운 릴레이에 참여할 수 있는 **Android UI 구현**
- 릴레이 생성·조회·참여 과정의 **화면 및 데이터 처리 로직 개발**

### 3. Kotlin 도입 및 앱 구조 개선

- 기존 Java 기반 Android 프로젝트에 **Kotlin 도입**
- 신규 기능부터 Kotlin을 적용하여 **점진적인 코드베이스 전환**
- **MVP 아키텍처를 적용**하여 UI와 비즈니스 로직의 역할 분리
