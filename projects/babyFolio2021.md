## 📝 개요

아이의 성장 과정을 사진과 영상으로 기록하고
가족 구성원과 함께 공유할 수 있는 **육아 성장 기록 서비스**입니다.

**Android 메인 개발자**로 참여하여 앱 아키텍처 개선,
AI 기반 콘텐츠 기능, 인앱 재화·결제 기능 등
서비스의 주요 Android 기능을 개발했습니다.

또한 Bitbucket Pipeline을 활용한 배포 자동화와
Datadog 기반 모니터링 환경을 구축하여
서비스 개발·운영 환경을 개선했습니다.

## 🚀 주요 기여

### 1. 인앱 재화 및 결제 기능 개발

- 서비스 내에서 사용할 수 있는 **인앱 재화 시스템 개발**
- 재화 구매를 위한 **인앱 결제 기능 구현**
- 구매 결과에 따른 재화 지급 및 **결제 상태 처리 로직 개발**
- 서비스 수익화 기능의 **요구사항 및 로직 설계 과정 참여**

### 2. AI 이모티콘 '쑥티콘' 개발

- TensorFlow 기반 이미지 처리 기능을 활용한 **개인화 이모티콘 생성 기능 개발**
- 사용자가 등록한 이미지를 기반으로 콘텐츠를 생성할 수 있도록 **Android 기능 및 UI 구현**
- 생성된 이모티콘의 **저장·조회 및 사용자 화면 연동**
- 출시 후 1개월 내 **약 30만 건의 이모티콘 제작**

### 3. Android 앱 구조 개선

- MVVM · Clean Architecture 기반으로 **Android 앱 구조 개선**
- 기존 Java와 Kotlin이 혼재된 프로젝트에서 **Kotlin 기반 신규 기능 개발**
- UI · 비즈니스 로직 · 데이터 영역의 역할을 분리하여 **기능별 코드 구조 정리**

### 4. 배포 및 모니터링 환경 구축

- Bitbucket Pipeline을 활용한 **Android 빌드·배포 자동화 구성**
- Datadog을 연동하여 **앱 오류 및 성능 모니터링 환경 구축**
- 서비스 운영 과정에서 발생하는 **Android 이슈 확인 및 대응**
