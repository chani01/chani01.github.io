## 🚀 주요 기여

### 1. Firebase → Supabase 마이그레이션
- **Supabase 프로젝트 세팅 직접 구성** — DB 스키마 설계, Auth 설정, Storage 등 백엔드 환경 구축
- Cloud Firestore에서 **Supabase(PostgreSQL)로 전면 전환**, SQL 기반 유연한 데이터 관리 환경 구축
- Supabase Auth 기반으로 SNS 로그인·생체 인식을 **일관된 인증 플로우로 통합**

### 2. SNS 로그인 시스템 구축
- Google·Kakao·Naver SNS 로그인 연동으로 **사용자 진입 장벽 최소화**
- 인증 토큰 자동 갱신 및 **세션 관리 로직** 구현

### 3. 생체 인식 인증 도입
- **Biometric API** 연동으로 지문·얼굴 인식 기반 간편 인증 구현
- 민감한 꿈 기록 데이터 보호를 위한 **추가 인증 레이어** 구축
