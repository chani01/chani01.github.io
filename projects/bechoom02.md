## 🚀 핵심 기능 구현
**개발 기여도 100%**로 인증 시스템 전면 구축과 백엔드 인프라 전환을 전담했습니다.

### 1. SNS 로그인 시스템
* **소셜 인증 통합**: Google, Kakao 등 SNS 로그인을 Supabase Auth 기반으로 구현하여 사용자 진입 장벽 최소화
* **토큰 관리**: 인증 토큰의 자동 갱신 및 세션 관리 로직 구축

### 2. 생체 인식 인증
* **Biometric API 연동**: 지문, 얼굴 인식 등 안드로이드 생체 인식 기능을 도입하여 간편하면서도 안전한 인증 경험 제공
* **보안 강화**: 민감한 꿈 기록 데이터 보호를 위한 추가 인증 레이어 구현

### 3. Supabase 백엔드 전환
* **DB 마이그레이션**: Firebase Cloud Firestore에서 Supabase(PostgreSQL)로 전면 전환하여 SQL 기반의 유연한 데이터 관리 환경 구축
* **인증 통합**: Supabase Auth를 활용한 통합 인증 시스템 구축으로 SNS 로그인과 생체 인식의 일관된 인증 플로우 구현
