## 📝 개요

히든태그의 정품 인증 기술을 기반으로
**어바웃미·휴롬 등 고객사별 전용 모바일 앱을 개발한 B2B 프로젝트**입니다.

**Android · iOS 단독 개발자**로 참여하여
정품 인증 라이브러리 연동부터 고객사별 UI 및 기능 개발,
중국 모바일 환경 대응과 앱스토어 배포까지 담당했습니다.

고객사별 요구사항은 개별적으로 대응하면서
공통으로 사용할 수 있는 기능과 코드를 분리하여
여러 고객사 앱을 관리할 수 있도록 앱 구조를 구성했습니다.

## 🚀 주요 기여

### 1. 고객사 전용 정품 인증 앱 개발

- 히든태그 **정품 인증 라이브러리를 Android/iOS 앱에 연동**
- Camera API를 활용한 **제품 촬영 및 정품 인증 기능 구현**
- 어바웃미·휴롬 등 고객사별 요구사항에 맞춘 **전용 기능 및 UI 개발**
- 인증 결과에 따른 **화면 및 사용자 흐름 구현**

### 2. 다수 고객사 앱 구조 관리

- 여러 고객사 앱에서 공통으로 사용하는 **정품 인증 및 공통 기능 코드 분리**
- 고객사별 UI·설정·기능을 적용할 수 있도록 **앱 구조 구성**
- 고객사 요구사항에 따른 **기능 추가 및 유지보수**
- 공통 기능 변경 시 여러 고객사 앱에 적용할 수 있도록 **공통 코드 관리**

### 3. 중국 서비스 현지화 및 배포

- Google 서비스를 사용할 수 없는 중국 Android 환경에 대응하여 **Baidu Push 연동**
- **WeChat · QQ** 등 중국 현지 SNS 기능 연동
- 중국 모바일 환경에 필요한 **앱 기능 및 SDK 대응**
- 바이두·화웨이·샤오미·오포·텐센트 등
  **중국 주요 8개 앱스토어 빌드 및 배포 대응**
