## 📝 개요
구독/포인트 수익 시스템과 커뮤니티 기능을 Android 메인 개발자(기여도 85%)로 주도, 사용성 만족도 84.8% 및 가족 네트워크 확장 달성

## 📈 핵심 성과
| 지표 | 결과 |
|------|------|
| 사용성·디자인 만족도 | 고객 설문 **84.8%** 긍정 응답 |
| 가족당 구성원 수 | 평균 **4명 → 6명** 증가 |
| 매출 | 구독·프리미엄 영상 출시로 **지속 상승** |
| 유저 인게이지먼트 | 챌린지·공개 일기로 체류 시간 증대 |

## 🛠 기술 스택
`Kotlin` `Java` `Jetpack Compose` `Room` `Firebase` `Datadog` `Bitbucket` `Firebase App Distribution`

# 🚀 주요 기여

### 1. 구독·포인트 수익 시스템 구축
- 정기 구독 시스템 및 프리미엄 영상 제작 기능 출시로 **수익 구조 안정화**
- 활동 기반 무료 포인트 지급으로 **앱 내 경제 선순환 구조** 설계 및 구현

### 2. 소셜 커뮤니티 기능 개발
- 공개 일기·챌린지 기능으로 **유저 간 상호작용** 활성화
- 홈 화면 3·4차 개편으로 복잡한 기능을 직관적으로 접근 가능하게 개선

### 3. 서비스 라이프사이클 확장
- 출산 전 단계 관리 기능 추가로 **예비 부모까지 유저 층 확대**
- 사진책 등 굿즈 라인업 추가로 커머스 기능 고도화
